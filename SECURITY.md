# Security Policy

## Supported Versions

This project is under active development. Security fixes are applied to the latest `main` branch.

## Reporting a Vulnerability

If you discover a security issue, please **do not open a public issue**.

Contact: `felipearanha.c@gmail.com`

Please include:
- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

We will acknowledge receipt as soon as possible and work on a fix before public disclosure.

## Security Best Practices for Contributors

- Never commit secrets, tokens, API keys, or private certificates.
- Use `.env` files locally; keep secrets out of version control.
- Keep dependencies up to date.
- Prefer least-privilege credentials for external services.
